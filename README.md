# Ars Anima: Il’Inconnu

El proyecto y el juego se llama y debe llamarse: Ars Anima: " Il'INCONNU "

Haz que las armas se gasten de a poco o puedan fallar, y en el inventario crafteando se puedan arreglar con recursos ya obtenibles, mejorar, añadir efectos o subir de nivel, o por el vendedor

Haz que las armas se gasten de a poco o puedan fallar, y en el inventario crafteando se puedan arreglar con recursos ya obtenibles, mejorar, añadir efectos o subir de nivel, o por el vendedor, tambien haz que se puedan comparar armas, y armaduras en el inventario con el que esta uesto y el que esta seleccionado por el mouse

Haz que algunos enemigos disparen bombas hacia arriba lanzandolas, o otros se lanzan al jugador corriendo y exploten muriendo pero causando daño al jugador, haz que algunos disparen proyectiles como si ocuparán armas a distancia como el jugador. Y haz que el jefe o los jefes entre sus movimientos nuevos, puedan generar nubes alrededor de ellos de proyectiles con patrones aleatorios que se pongan a rebotar contra las paredes, techo y mapa. Quiero que el juego parezca o tenga cierta similitud a un bullet hell

Agrega un tema claro alterno a el oscuro de ahora (Aternable/selecionable) y un boton rgb para jugar
